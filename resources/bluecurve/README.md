# Bluecurve icons

This directory contains a focused subset of the Red Hat Bluecurve action
icons used by uil. The size-specific SVG files come from commit
`013ba225e78d9767b274ac6f16a67cb19f0673c6` of the Bluecurve GTK 3/4
restoration at https://github.com/neeeeow/Bluecurve, whose scalable icons
were exported from the original Adobe Illustrator sources.

The vendored artwork is licensed under GNU GPL v3.0; see `LICENSE.txt`.
The icon names are retained from the source theme, and the artwork is
otherwise unmodified.
