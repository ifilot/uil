# Atomic-orbital example

This three-slide Beamer presentation embeds hydrogen-like `2s`, `2pz`, and
`3dz2` orbital definitions directly in its PDF. Build and copy the presentation
to `examples/bundled` with:

```sh
make
```

The static TikZ posters are visible in every PDF reader. UIL replaces each
poster with the OpenGL 3.3 orbital and signed-wavefunction contour renderer.
